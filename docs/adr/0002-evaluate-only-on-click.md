# Evaluate only when the Candidate clicks

leauto doesn't read a Thread or change LinkedIn's page until the Candidate presses one of its buttons. It doesn't evaluate passively when a Thread opens, doesn't add badges to the inbox list, and doesn't pre-compute Drafts. Automatic evaluation would be more convenient. We chose click-only to keep the extension inactive by default, which lowers the chance that LinkedIn detects automation and keeps it clearly human-in-the-loop. It also means no message text is processed unless the Candidate asks for it.
